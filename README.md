# TCE — сайт

Статическая сборка на Eleventy (11ty). Партиалы (header/footer) в `src/_includes`, страницы в `src/`, стили в `src/css`.

## Разработка

```
npm install
npm run dev
```

Локальный сервер поднимется на `http://localhost:8080`.

## Сборка

```
npm run build
```

Результат — чистый статический сайт в `_site/` (готов к заливке на любой хостинг, включая hoster.by).

## Деплой

Репозиторий подключён к Vercel для превью-версий во время разработки. Финальный прод — hoster.by.
